# 🧠✨ SentixAI – Machine Learning Text Sentiment Analyzer

SentixAI is a modern, responsive, and production-ready **Natural Language Processing (NLP)** web application that analyzes the sentiment of user-provided text in real time.

The application utilizes a custom-trained **Scikit-Learn Machine Learning Pipeline**, consisting of a **TF-IDF Vectorizer** and a **Binary Logistic Regression Classifier**, to accurately classify text as **Positive** or **Negative**.

Built with **Flask** for the backend and **Tailwind CSS** for the frontend, SentixAI delivers an attractive user interface featuring confidence scores, interactive visualizations, AJAX-powered predictions, and a modern dark-themed design.

When deployed, SentixAI provides:

- 🟢 **Real-Time Predictions**
  - Instantly analyzes text using asynchronous AJAX requests without refreshing the page.

- 🎨 **Dynamic User Interface**
  - Automatically changes the interface theme based on prediction results.
  - **Emerald Green** for Positive sentiment.
  - **Rose Red** for Negative sentiment.

- 📈 **Prediction Confidence**
  - Displays the exact confidence percentage generated by the machine learning model.

- ⚡ **Fast & Responsive**
  - Lightweight frontend with smooth animations and instant feedback.

- 🌙 **Modern Dark UI**
  - Glassmorphism-inspired design with Tailwind CSS.

# 💻 Local Setup & Installation

## 1. Clone or Create the Project Folder

Create a new folder and place the following files inside it:

- `app.py`
- `requirements.txt`
- `vectorizer.pkl`
- `model (1).pkl`

---

## 2. Create a Virtual Environment (Recommended)

### Windows

```bash
python -m venv venv
venv\Scripts\activate
```

### macOS / Linux

```bash
python -m venv venv
source venv/bin/activate
```

---

## 3. Install Dependencies

```bash
pip install -r requirements.txt
```

---

## 4. Run the Application

```bash
python app.py
```

Open your browser and visit:

```
http://127.0.0.1:5000
```
